# Personal library

One organized place for the articles, videos and posts I save across X,
Reddit, Facebook, LinkedIn, YouTube and daily.dev, with my own notes,
collections, tags and search.

## Status

Early development. Currently building the MVP.

## Structure

| Path | What it is |
|---|---|
| `backend/` | FastAPI API and database |
| `apps/web/` | React web app, installable on mobile |
| `apps/extension/` | Browser extension for saving pages |
| `packages/api-client/` | Generated TypeScript types for the API |
| `docs/` | Project brief, roadmap, dev log, setup guide and ADRs |
| `.claude/commands/` | Claude Code workflow commands |
