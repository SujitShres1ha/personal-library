description: Work out what to do next and plan it
---

Help me decide and plan my next piece of work.

1. Read `docs/roadmap.md`, the most recent entries in `docs/dev-log.md`, and
   the current state of the repository.
2. Tell me which roadmap step I am on, or which step should come next, based on
   what is done and what each step needs first. Prefer MVP steps.
3. For that step, give me:
   - what we will build, and its "Done when" line
   - a plan of small, separately committable tasks
   - the concepts I will learn, with one sentence each
   - a branch name and a likely first commit message
4. Ask whether I want to write any part myself before we start. Do not write
   code yet.
